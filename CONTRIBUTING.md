# Contributing to SecureFile

Thank you for considering contributing!

## Reporting Bugs

- Check existing issues first
- Open a new issue with browser version and steps to reproduce

## Suggesting Features

- Open an issue with the label enhancement
- Explain the use case clearly

## Submitting Code

1. Fork the repository
2. Create your branch: git checkout -b feature/YourFeatureName
3. Commit: git commit -m feat: describe your change
4. Push: git push origin feature/YourFeatureName
5. Open a Pull Request

## Code Style

- Clear descriptive variable names
- Comment all cryptographic logic
- Test in Chrome Firefox and Edge
- No unnecessary external dependencies

## Commit Types

feat | fix | docs | style | refactor | security | chore
